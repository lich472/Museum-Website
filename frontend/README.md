# Frontend

React + TypeScript + Vite. See the repository README for commands.

- `src/features/bookings/`: P2 ticket booking pages and components.
- `src/features/memberships/`: P2 membership pages and components.
- `src/components/`: shared components.
- `src/App.tsx`: shared application entry.

The initial page contains placeholders only; booking and membership logic are not implemented yet.
